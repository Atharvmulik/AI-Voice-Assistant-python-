# AI-Voice-Assistant-python-

A simple and intelligent voice assistant built using Python that can listen to your voice commands, process them, and respond with spoken output. This project demonstrates how to integrate speech recognition and text-to-speech in Python to build a personal assistant.

✨ Features

🎙️ Voice Input — Listens to user commands via the microphone

💬 Speech Recognition — Converts spoken words to text

🤖 Command Handling — Responds to common commands (like time, date, open apps, etc.)

🗣️ Text-to-Speech Output — Speaks back responses using TTS

🌐 Web Integration — Can search the web or open websites on command
